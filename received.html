What a PASS asserts

  • The packet's sections are byte-for-byte unchanged since Hardseal sealed it — the recomputed SHA-256 chain root matches the stored root.
  • The recorded finding, objective mapping, reviewer question, and limitations were not edited after sealing.
  • The same result is reproducible offline by anyone — in this browser, in the stdlib-only Python verifier, or in any independent reimplementation of the documented algorithm.
  • No overclaiming language is present: the sealed text is scanned for banned phrases (e.g. “we certify”, “assessor-ready”) and a PASS means none were found.

What a PASS does not assert

  • It is not a certification of CMMC or NIST SP 800-171 compliance.
  • It is not a C3PAO assessment result or a substitute for one.
  • It does not prove customer facts, complete evidence coverage, or physical truth about the supplier's environment.
  • It does not make a final assessment determination. Hardseal records whether the packet matches the anchored finding under explicit, stated assumptions.

Verify it yourself

  1. Open the verification link the supplier gave you, or click “Verify the packet now” above. It loads at hardseal.ai/v/?id=<receipt-id>.
  2. The page recomputes the SHA-256 chain root in your own browser from the raw packet JSON. Nothing is sent to Hardseal.
  3. A green “Seal verified” state means the recomputed root matched the stored root. Click “Run full verification yourself” to watch every check execute.
  4. Want an air-gapped check? Download the packet JSON and the stdlib-only Python verifier from the same page and run python3 verify_cmmc_packet_qa.py verify <receipt.json>. Same answer, no network.
Why this matters to you. A binder or PDF asks you to trust the firm that produced it. A Hardseal packet asks you to trust math you can run yourself. If a single character of the sealed finding changes, the chain root no longer matches and verification fails — and the verifier names the first section that was altered. That is the difference between an attestation and a primitive.
